# lee-internal-comps

A Claude plugin for authorized Lee & Associates Raleigh brokers. Lets Claude pull internal Dealius lease and sale comps (Excel + Lee-branded PDF) plus external comps (Excel + Markdown table) via typed MCP tools, with broker-tour email drafts on every pull.

## Install

Install via the GI marketplace — see [parent README](../../README.md).

## What you get

- **Skill:** `internal-comps` — orchestrates a comp search against the firm's internal Dealius mirror, builds the Excel deliverable, and renders a Lee-branded PDF (broker chooses Excel / PDF / Both per request).
- **Skill:** `external-comps` — orchestrates a comp search against the external weekly snapshot, produces a Markdown table in chat plus an Excel deliverable, and drafts a tour-ready email. PDF deferred to v1.1.
- **Skill:** `internal-and-external-comps` — the **default** "all comps" skill: an unqualified comps request (broker didn't say internal or external) pulls **both** internal Dealius and external CoStar in parallel and returns one combined chat table, one Excel (All Comps sheet + per-source detail sheets), and one Lee-branded **unified PDF** with every row tagged by Source. No dedup; sale and lease. Explicit "internal comps" / "external comps" still route to the single-source skills.
- **Skill:** `demographic-summary` — single-page 1/3/5-mile demographic infographic for any NC address (JSON + Lee-branded PDF with a 1-hour signed link).
- **Skill:** `demographic-detail` — multi-page Demographic and Income Profile with inline SVG charts, race/income breakdowns, 2020/2025/2030 projections (gi_permit_adjusted + Census BPS add-back), Family HHs + Owner HUs trend bars, and four Esri-analog indices.
- **Skill:** `business-key-facts` — BAO-style Business Key Facts 3-page landscape PDF for any NC address: key statistics, households table, site map with 1/3/5-mile rings, education attainment + workforce charts, population/housing growth.
- **Skill:** `owner-lookup` — sub-second owner-of-record + mailing address + assessor facts for any property in Wake, Durham, New Hanover, or Lee NC. Backed by a ~2M-row D1 owner graph bulk-staged from each county's GIS endpoint (no live external calls on the request path).
- **Skill:** `parcel-lookup` — the full county property record for any covered NC address: owner + mailing, PIN, lot/building facts, tax value, last sale, zoning with ordinance link, and the last 5 years of building permits (Raleigh, Cary, Durham, New Hanover feeds), with a pl-card flyer fragment + Lee-branded Property Facts PDF. Backed by the same bulk-staged D1 parcel substrate as owner-lookup plus a parcel_permits table (no live county calls on the request path).
- **Skill:** `daily-debrief` — Will-only interview-style classification of yesterday's plugin sessions; walks Will through each session, records his outcome classification (plugin_only / plugin_with_manual_fix / manual_only / unable) and broker request source, and feeds the Friday usage rollup in #all-groundedintelligence.
- **Skill:** `tenants-in-market` — scheduled Cowork ingest of Triangle Pairlist tenant-requirement emails. Screens each as a tenant requirement (broker seeking space/investment) vs a listing (broker marketing a property), extracts the requirement fields, and writes every screened email to a shared, queryable `tenant_requirements` store (audit-everything) via the `lee_tenant_requirement_write` tool. Analyst/automation skill, not broker-invoked.
- **Skill:** `tenant-search` — the query half of tenants-in-market: "what tenants are in the market for 5-10k SF industrial in Garner?" Searches the shared `tenant_requirements` pool via the `pull_tenants_in_market` tool (asset type, size, location, recency) and returns matches with the originating broker's contact so a broker can pair a listing. Size accepts a single `target_sf` (matched in a ±30% tolerance band by range overlap) or an explicit `min_sf`/`max_sf` window; `location` accepts a city or a county name that rolls up to its cities ("Wake County" → Raleigh/Cary/Apex/...), and multi-location tenants match on any one location. Only queryable space requirements surface — investment/$-budget ISOs and listings stay audit-only. Broker-facing, read-only.
- **Skill:** `owner-mailing-list` — deduplicated owner + mailing-address CSV for an area + criteria request ("owners of 2–5 acre vacant land within 3 miles of 100 Walnut St, Cary"). Calls the lee-raleigh connector's `pull_owner_mailing_list` tool against the pre-staged NC OneMap statewide parcel mirror — radius + acreage + land-class criteria, private owners only, deduped by mailing address, results in seconds. No browser extension. Covers Wake, Durham, New Hanover, Lee, Orange, Johnston, Chatham (NC); adding a county is a data refresh, not new code.
- **Skill:** `add-comps` — normalize a contributed comp set a broker pastes, forwards, or uploads (a forwarded email with several brokerage comp tables, an xlsx/csv export, a pasted table, or a screenshot) into canonical records tagged by source/provenance, and ingest them into the comps database (a third source alongside Dealius + CoStar) via the `lee_comps_add_write` MCP tool. Handles lease and sale; flags (never drops) incomplete rows for review. Queryable across all three sources via `pull_unified_comps`. Analyst/operator skill.
- **Skill:** `process-mapping` — a guided interview that helps anyone at the firm (any function) map one of their own repeatable processes into a clean, linear, text-only process document — before any automation. Opens with Grounded Intelligence branding, walks five gates (intake → optional existing-material ingest → trigger/end-state → step-by-step interview → full-flow restatement → structured handoff), and ends by drafting an email that sends the finished map back to GI for the next phase. Not a comps tool; CRE shows up only as firm context, the user's role stays agnostic.
- **Skill:** `nearby-businesses` — Area Amenities map kit for any NC address: the recognizable nearby businesses (grocery, retail, restaurants, coffee, gyms, pharmacies, hotels, healthcare) ranked by prominence with their brand logos, laid out on a basemap with 1/3/5-mile rings, returned as a downloadable designer kit (basemap + `logos/` + a `placements.json` manifest + Lee `brand.json`) behind a 15-minute signed link. The marketing team unzips it and composes the flyer's amenities map in Claude Design. Wraps the `lee-raleigh-mcp` `pull_nearby_businesses` tool; brand logos accumulate in R2 across pulls.
- **Skill:** `comp-map` — put your comps on a Lee-branded Google map for an NC listing. **Deal mode** (a subject address): maps the comps *around* it — numbered pins ordered by distance, optional radius rings, and a paired comp table whose rows match the pins. **Database mode** (no subject): maps the whole internal comp set, or a broker's deal history ("map every deal my team closed in this market"). Returns a shareable ~30-day interactive Google map link (forward it to a client), a print-ready static PNG, and a `csm-*` comp-table fragment for flyers/OMs/BOVs. A single map shows at most ~10% of the database (governance cap; surfaced when it fires). Distance rings only in v1 (drive-time bands tracked separately). Wraps the `lee-raleigh-mcp` `pull_comp_map` tool.
- **Skill:** `development-pipeline` — the commercial development pipeline around any covered NC address: what's being built, approved, or under review within a radius (default 3 mi), from 12 pre-staged municipal feeds (Raleigh, Cary, Durham, Apex, Garner, Morrisville, Wake County unincorporated, Wake Forest, Chapel Hill, Harnett, Lee County NC, New Hanover/Wilmington). The broker picks the product types (office / retail / industrial / multifamily / mixed use / hospitality / institutional / residential, or all); minor works and amendment duplicates are screened automatically with per-category exclusion counts reported. Returns stage counts, a sorted project table, flyer-ready narrative bullet lines (the nearby-development copy brokers hand-write today), a `dpt-*` flyer fragment, and a component PDF. Data is staged nightly into the Lee data engine — no live municipal calls at request time — and accumulates per-project status-transition history the counties overwrite. Wraps the `lee-raleigh-mcp` `pull_development_pipeline` tool.
- **Skill:** `drive-time-isochrones` — how far you can get from a property in N minutes. Drive-time reach polygons (isochrones) for any NC address: 5/10/15 minutes by default, configurable 1–60, by car, on foot, or by bike — the trade-area answer that replaces crude mile rings. Returns per-band reach areas in sq miles, the isochrone GeoJSON for downstream maps, an `dti-*` polygons-only SVG fragment, and a Lee-branded map card PDF (reach polygons over an OSM basemap). Free-flow travel times in v1 (no rush-hour adjustment). Wraps the `lee-raleigh-mcp` `pull_drive_time_isochrones` tool.
- **Skill:** `site-infrastructure` — who serves this site: the documented utility baseline for any NC address. Five rows — broadband (broker-verified, with a parcel-centered FCC National Broadband Map link as the verification starting point), electric (HIFLD retail service territories, overlapping territories all surfaced), water and sewer (New Hanover + Lee county GIS -> 2004 NC OneMap service areas -> curated 12-county registry ladder), and natural gas (curated registry) — each with a confidence tag and source provenance, plus an `si-card` flyer fragment and a Lee-branded component PDF. Capacity figures (MW, gpm, allocation, pressure) are deliberately out of scope; the card's footer says so. Wraps the `lee-raleigh-mcp` `pull_site_infrastructure` tool.
- **Skill:** `lee-branding` — apply the official Lee & Associates brand to a deliverable, or set up the Lee design system in Claude Design once so every design comes out on-brand automatically. Ships Lee's official brand package on disk — the logo (SVG + PNG), the exact color values (`brand-colors.json` + full brand guidelines), and the Avenir Next brand fonts (WOFF) — plus a step-by-step Claude Design setup guide and the logo/color usage rules. The canonical on-disk home for the Lee logo (the in-session comps skills bundle their own byte-identical copy because the Cowork sandbox can't fetch assets at runtime). No server call — the assets are bundled.
- **MCP connector:** `lee-raleigh` — read-only access to your firm's internal Dealius mirror, external comp tools, demographic infographics, and the cross-county owner graph, gated by OAuth + magic-link sign-in. Authorized brokers are pre-provisioned by Grounded Intelligence.

## External comps

The `external-comps` skill wraps three typed MCP tools (`search_external_sale_comps`, `search_external_lease_comps`, `get_external_comp_detail`) on the same `lee-raleigh` connector. The data lands weekly from Will's Excel export via the `external-comps-db` ingest pipeline. v1 produces Markdown + Excel; a Lee-branded PDF path is planned for v1.1.

## Sign-in

The first time the skill calls a tool, Cowork prompts an OAuth sign-in. You'll be redirected to a Lee Raleigh login page; enter your `@lee-associates.com` email, click the magic link in your inbox, and you're set. The session lasts 30 days; new magic link required after that.
