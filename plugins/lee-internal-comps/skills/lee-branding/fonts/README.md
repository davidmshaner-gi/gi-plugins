# Fonts — Lee & Associates brand typefaces

The actual Lee brand fonts in web format (WOFF). Add them to Claude Design alongside the
brand guidelines so designs render in the real brand typefaces instead of fallbacks.

## Avenir Next — primary typeface
| File | Use | Weight / style |
|---|---|---|
| `AvenirNextCyr-Regular.woff` | Body copy | Regular (400), upright |
| `AvenirNextCyr-Italic.woff` | Body italic | Regular (400), italic |
| `AvenirNextCyr-Medium.woff` | Emphasis / subheads | Medium, upright |
| `AvenirNextCyr-MediumItalic.woff` | Medium italic | Medium, italic |
| `AvenirNextCyr-Bold.woff` | Headings | Bold, upright |

## Minion Pro — accent / headline serif
| File | Use | Weight / style |
|---|---|---|
| `MinionPro-Regular.woff` | Serif body / specimen | Regular (400), upright |
| `MinionPro-It.woff` | Serif italic | Regular (400), italic |
| `MinionPro-Medium.woff` | Serif emphasis | Medium (500), upright |
| `MinionPro-MediumIt.woff` | Serif medium italic | Medium (500), italic |
| `MinionPro-Semibold.woff` | Pull quotes / accents | Semibold (600), upright |
| `MinionPro-SemiboldIt.woff` | Semibold italic | Semibold (600), italic |
| `MinionPro-Bold.woff` | Serif headline | Bold (700), upright |
| `MinionPro-BoldIt.woff` | Bold italic | Bold (700), italic |

Source OTFs (all 10 weights, incl. the condensed cuts we don't use in-brand) are in
`minion-pro/`. The WOFFs above were converted losslessly from those OTFs with fonttools.

## Notes

- **Minion Pro** is now bundled (converted 2026-07-14) — the accent/headline serif named
  in the guidelines. Georgia remains the fallback if a weight is missing.
- **Licensing.** These are commercial licensed brand fonts — Avenir Next and Minion Pro
  (Adobe). Keep them within Lee & Associates and embedded in finished designs; do not post
  the raw font files for public download.
