# Fonts — Avenir Next (Lee & Associates primary typeface)

These are the actual Avenir Next font files for the Lee brand, in web format (WOFF).
Add them to Claude Design alongside the brand guidelines so designs render in the real
brand typeface instead of a fallback.

| File | Use | Weight / style |
|---|---|---|
| `AvenirNextCyr-Regular.woff` | Body copy | Regular (400), upright |
| `AvenirNextCyr-Italic.woff` | Body italic | Regular (400), italic |
| `AvenirNextCyr-Medium.woff` | Emphasis / subheads | Medium, upright |
| `AvenirNextCyr-MediumItalic.woff` | Medium italic | Medium, italic |
| `AvenirNextCyr-Bold.woff` | Headings | Bold, upright |

## Notes

- **Minion Pro** (the accent / headline serif named in the guidelines) is **not yet
  included** — Lee has not provided it. Use the Georgia fallback until it arrives.
- **Licensing.** These are Lee's licensed brand fonts. Keep them within Lee & Associates
  and embedded in finished designs; do not post the raw font files for public download.
